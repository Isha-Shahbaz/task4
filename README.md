# Data Science Tool Mastery Project

## Project overview
A beginner-friendly retail sales analysis project demonstrating Python data science tools:
- **NumPy** for numerical operations
- **Pandas** for loading, cleaning, grouping and summarizing data
- **Matplotlib** and **Seaborn** for charts
- **Scikit-learn** is listed as an additional library to explore; this starter analysis does not train a machine-learning model.

## Dataset
`retail_sales_sample.csv` is a small illustrative/sample dataset created for practice. It is not real customer or company data.

## Setup
1. Install Python 3.10 or newer.
2. Open this folder in VS Code.
3. In the terminal, optionally create and activate a virtual environment.
4. Install libraries:

```bash
pip install -r requirements.txt
```

## Run
```bash
python analysis.py
```

The script prints descriptive statistics and grouped revenue summaries. It creates an `outputs/` folder containing cleaned data and three charts.

## Skills demonstrated
- Reading a CSV file with Pandas
- Parsing dates and checking/removing duplicate rows
- Handling missing or invalid numeric values
- Creating a calculated Revenue column
- Descriptive statistics and correlation
- Grouping and aggregating data
- Creating bar and line charts
- Organizing a small Python project

## Important
The included data and results are for educational practice. Review the generated output and update the report with your own observations before submitting.
